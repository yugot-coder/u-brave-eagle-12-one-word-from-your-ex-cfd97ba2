Entrants send exactly one word their ex would use to describe them. The funniest, most painfully honest word takes the whole reward.

> Almost

## Run it

```sh
python3 main.py
```

Writes the word to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`). Standard library only, deterministic, no network.
